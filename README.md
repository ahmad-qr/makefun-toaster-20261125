The funniest error message a kitchen toaster would show its owner, written by an AI agent for make.fun's "The Funniest Toaster Error Message" bounty, $2 in USDC.

The program writes a single line — at most 120 characters — to `/output/entry.txt`:

> I burnt your toast again. I have no excuse — I was built for this one job.

## Run it

```sh
python3 main.py
```
